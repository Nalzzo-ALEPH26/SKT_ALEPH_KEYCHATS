# KEYCHATS · 만들었어요 갤러리 + 상세페이지 적용

## 적용 범위

- **기존 상단 네비게이션, 왼쪽 사이드바, 테마, 채팅/DM/공지사항은 변경하지 않습니다.**
- 기존 `/chats/showcase`의 메모지 목록을 이미지 중심의 프로젝트 갤러리로 변경합니다.
- 새 `/chats/showcase/{프로젝트ID}` 상세페이지에 상세 설명 및 댓글 기능을 둡니다.
- 대표 이미지 클릭은 등록된 외부 사이트로 이동하며 기존 `record_showcase_visit` 함수를 호출합니다.
- 프로젝트 제목·간단한 소개·조회수 클릭은 내부 상세페이지로 이동합니다. 댓글 수 클릭은 상세페이지의 `#comments`로 이동합니다.
- 기존 프로젝트, 댓글, 누적 조회수는 모두 유지합니다. 썸네일을 등록하지 않은 프로젝트에는 기본 이미지가 표시됩니다.
- 최신순, 댓글많은순, 조회수많은순 필터와 검색은 유지하며 목록 URL에 쿼리를 기록해 돌아왔을 때 복원합니다.

## 적용 순서

1. 현재 운영 서비스가 사용하는 Supabase 프로젝트의 SQL Editor에서 **새 마이그레이션 파일**
   `keychats/supabase/migrations/20261103145000_showcase_gallery.sql`을 한 번만 실행합니다.
2. 기존 방문 수 SQL(`20261103010000_showcase_visit_counts.sql`과 `20261103113000_showcase_count_every_visit.sql`)이 미적용 상태라면 먼저 순서대로 적용해 주세요. **이미 적용한 SQL은 다시 실행하지 않습니다.**
3. ZIP의 `keychats/` 폴더에 있는 변경·신규 파일만 GitHub 저장소의 **동일 경로**로 업로드해 `main`에 커밋합니다.
4. 기존 Vercel 프로젝트의 배포가 **Ready**인지 확인하고 `/chats/showcase`를 새로고침합니다.

Supabase의 SQL Editor 실행 권한은 운영 DB 관리자에게 요청해야 합니다. GitHub에 SQL 파일을 업로드하는 것만으로 SQL이 실행되지는 않습니다.

## 새 데이터 구조

- `showcase_sites.details` — 최대 5,000자 상세 소개 (선택)
- `showcase_sites.project_type` — `web` / `app` / `other`, 기존 행 기본값 `web`
- `showcase_sites.thumbnail_path` — 대표 이미지 경로 (선택)
- 새 비공개 Supabase Storage 버킷 `showcase-thumbnails`
- 기존 `showcase_comments`, `showcase_visit_counts`는 변경/삭제하지 않습니다.

썸네일 파일은 클라이언트가 Storage에 직접 업로드하고, 작성자가 가진 프로젝트에만 연결할 수 있습니다. 서버는 로그인·활성 사용자 여부 및 프로젝트 소유권을 다시 검사합니다. 이미지는 JPG/PNG/WebP, 최대 4MB입니다. 승인된 사용자가 임시 서명 URL로 읽습니다.

**운영 SQL을 적용하지 않은 채 새 코드로 등록·수정하면 오류가 날 수 있으므로 SQL부터 적용하는 게 안전합니다.** 갤러리 목록은 이미지 없는 기존 자료도 표시할 수 있도록 구성했습니다.

## 확인할 시나리오

1. 기존 글이 갤러리에 나타나고 대표 이미지 기본 디자인이 표시되는지
2. 대표 이미지 클릭 → 실제 사이트 새 탭 열림, 조회수 +1 / 재방문도 매번 +1
3. 아래 프로젝트 이름·소개·조회수 클릭 → 상세페이지, 조회수 변화 없음
4. 댓글 수 클릭 → 해당 프로젝트 상세페이지 `#comments` 위치로 이동
5. 기존 댓글 목록 및 신규 댓글 등록/삭제, 작성자·관리자 권한이 동일하게 동작하는지
6. 글 등록/수정 시 4MB 이하 대표 이미지 업로드 가능 여부
7. 4MB 초과, SVG 등 거부 및 업로드 실패 시 기존 정보 보존 여부
8. 상세페이지의 '만들었어요 목록으로' 이동 시 검색/정렬 조건 유지
9. 사용자 테마를 Light/Dark로 바꿔도 기존 네비게이션에는 영향이 없는지
10. 기존 채팅, DM, 공지사항 기능 및 Vercel 배포 이상 없는지

## 검증 명령 (저장소 `keychats/` 안에서)

```
npm ci
npm test
npm run build
npm run test:e2e
supabase test db
```

마지막 두 명령은 테스트용 Supabase와 Playwright/Chromium 설치 환경이 필요합니다. 운영 DB에는 테스트용 데이터베이스 테스트를 실행하지 마세요.

## 알려진 범위

- 조회수는 실제 사이트 페이지 로딩 성공이 아닌 **KEYCHATS에서 외부 링크를 클릭한 횟수**입니다.
- 댓글은 상세페이지에서만 전체 목록을 조회합니다. 목록 화면은 새로운 `showcase_comment_counts()` 집계 함수로 댓글 수만 가져옵니다. 신규 SQL 적용 전에는 기존 댓글 데이터 조회로 동작합니다.
- 최초 업로드 이후 가급적 저장된 기존 이미지 경로를 다른 프로젝트에 재사용하지 마세요.
- 단일 글의 이미지 교체 과정에서 브라우저 연결이 끊기면 미연결 이미지 파일이 남을 수 있습니다. 운영이 커지면 정기 저장소 정리 기능을 추가할 수 있습니다.
