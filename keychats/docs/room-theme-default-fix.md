# 기본 채팅 디자인 복원

이 패치는 기존 공통 테마 기능이 업로드된 저장소용 수정입니다.
기준 main: 36cb9fcd2307f9b8551ff3247248ce78eb778337.

1. ZIP 압축을 풉니다.
2. 저장소 최상위에 keychats 폴더를 업로드하고 main에 커밋합니다.
3. Vercel 배포 성공 후 새로고침합니다.

추가 SQL은 필요하지 않습니다. 테마 저장/전체 참여자 동기화는 앞서 전달한 공통 테마 SQL 적용 후 사용할 수 있습니다.

- 기본 테마에서는 기존 채팅 배경과 글자색을 상속합니다. 기존 말풍선과 라이트/다크 스타일을 덮어쓰지 않습니다.
- 채팅창 위에 별도 테마 도구줄과 동기화 경고를 항상 표시하던 구성을 제거했습니다.
- 테마 버튼은 기존 채팅 헤더에 배치했습니다.
- 테마 선택은 팝업의 미리보기에만 반영되며, '모두에게 적용'을 누른 뒤 실제 방이 바뀝니다.
- '기본으로 복원'은 저장된 방 테마를 default로 변경합니다. 이미 다른 테마를 적용한 방에서는 이 버튼으로 되돌리세요.
- DB가 아직 준비되지 않은 경우 채팅 화면은 원래 디자인으로 유지되고, 저장 오류는 팝업 안에만 표시됩니다.
- 참여자 전체 공통 적용과 변경 권한은 그대로 유지합니다.
