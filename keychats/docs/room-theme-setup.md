# 대화방 공통 테마 적용 안내

## 적용 순서

1. 현재 KEYCHATS에 연결된 Supabase 프로젝트의 SQL Editor를 엽니다.
2. `keychats/supabase/migrations/20261029140000_conversation_themes.sql` 전체를 붙여 넣고 Run을 누릅니다. 정상 완료한 SQL을 다시 실행하지 마세요.
3. 압축을 푼 ZIP의 `keychats` 폴더를 GitHub 저장소 최상위에 업로드합니다. ZIP 자체를 올리거나 `keychats/keychats` 경로를 만들지 마세요.
4. main에 커밋하고 기존 Vercel 프로젝트가 Ready가 되는지 확인합니다.
5. 로그인 후 채널 또는 DM의 오른쪽 위 `대화방 테마`에서 선택 → 미리보기 → `모두에게 적용`을 누릅니다.

이 패치는 변경/추가 파일만 포함합니다. 기존 폴더를 삭제하지 마세요.
기준 main: 89df31797cfb1d18504d4a067eacb3f80689699d.
다른 기여자가 같은 파일을 먼저 변경했다면 최신 파일과 병합 후 업로드하세요.
기존 메모보드 SQL은 다시 실행할 필요가 없습니다.

## 동작과 권한

- 기본·크림·라벤더·민트·노을·미드나잇 6종.
- 대화방의 모든 참여자에게 동일한 테마가 적용됩니다. 개인별 덮어쓰기 설정은 없습니다.
- DM: 참여자 두 사람 모두 변경 가능.
- 일반 채널: 채널에 참여 중인 생성자 또는 관리자만 변경 가능.
- 기본 general 채널: 참여 중인 관리자만 변경 가능.
- 기본 테마 복원도 전체 참여자에게 적용됩니다.
- 왼쪽 사이드바는 유지하고 채팅 배경·말풍선·입력창 등에 적용합니다.
- 변경자와 마지막 변경 테마·시각을 대화방 상단에 표시합니다. 전체 변경 이력을 쌓는 기능은 아닙니다.
- 메시지를 생성하지 않으므로 테마 변경 자체로 안 읽은 개수·메시지 알림이 증가하지 않습니다.
- 실시간 수신 및 재접속/탭 복귀 시 DB 재조회, 실시간 연결 누락에 대비한 15초 보완 조회를 사용합니다.
- 입력 중인 메시지나 메시지 목록을 초기화하지 않고 테마만 변경합니다.
- SQL이 아직 적용되지 않았거나 연결에 문제가 있어도 기존 채팅은 사용할 수 있습니다. 테마 경고가 표시되면 SQL 적용과 연결을 확인하세요.

## 확인할 항목

1. 서로 다른 두 브라우저/계정으로 같은 DM 접속 → 한쪽에서 테마 변경 → 다른 쪽에도 반영되는지 확인.
2. 반대쪽에서도 변경하고 새로고침하여 유지 여부 확인.
3. 다른 방의 테마는 바뀌지 않는지 확인.
4. 일반 채널 멤버에게 변경 버튼이 없는지 확인.
5. 기본 테마 복원과 라이트/다크 화면에서 글자·첨부파일·링크·답장 표시 확인.

## 검증 명령

`npm test`, `npm run build`, `npm run test:e2e`, `supabase test db`.
브라우저 통합 테스트와 DB 권한 테스트는 로컬 Supabase 및 Chromium이 필요합니다.
새 브라우저 테스트는 두 참여자의 동기화·재접속·입력 중 메시지 보존·테마 변경 시 메시지 미생성을 검사합니다.
새 DB 테스트는 참여자 읽기/변경, 외부인·비활성 사용자 차단, 일반 채널 멤버 변경 금지 등을 검사합니다.
