## 2. GitHub 웹 업로드

ZIP을 먼저 압축 해제합니다. ZIP 파일 자체를 업로드하지 마세요.
저장소 최상위(기존 keychats 폴더가 보이는 위치)에서 Add file → Upload files를 선택합니다.
압축을 푼 뒤 나오는 `keychats` 폴더를 끌어 넣고 main에 커밋합니다.
이 ZIP은 추가/변경된 파일만 담은 패치입니다. 기존 폴더를 삭제하지 마세요.
`keychats/keychats` 또는 별도의 압축파일 이름 폴더가 생기면 업로드 위치가 잘못된 것입니다.
다른 팀원이 sidebar.tsx를 먼저 수정했다면 현재 파일과 병합한 뒤 업로드하세요.

## 3. 배포 확인

기존 Vercel 자동 배포 성공 후 로그인하여 COMMUNITY의 공지사항 바로 아래
`만들었어요 🔨` 메뉴를 확인합니다. 주소는 `/chats/showcase`입니다(기존 basePath 설정 유지).
오른쪽 등록 → 팝업 → 이름, URL, 소개, 색상, 태그 입력 → 등록.
다른 계정에서도 메모가 보이는지, 작성자만 수정 가능한지, 댓글과 삭제가 동작하는지 확인합니다.
관리자는 모든 메모/댓글 삭제가 가능합니다. 본인 메모를 삭제하면 연결된 댓글도 함께 삭제됩니다.
샘플 메모와 가상 사용자 데이터는 추가하지 않았습니다.
